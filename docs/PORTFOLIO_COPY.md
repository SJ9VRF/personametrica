# Portfolio copy

## Hero

**PersonaMetrica**  
An evolving personal intelligence system that learns a user over time, maintains a temporal world model, decides when to act or ask, verifies outcomes, and turns failures into evaluation and post-training data.

## One-line research question

Can a personal agent become more useful over time without becoming stale, intrusive, overconfident, or wrong?

## Evidence strip

Use only results regenerated by `python scripts/reproduce.py`. Current values come from the controlled synthetic benchmark and must not be described as human-study or frontier-model results.

## Suggested project-page flow

1. Research question and architecture.
2. 90-second longitudinal scenario showing preference drift.
3. Controlled benchmark results and targeted ablations.
4. Memory / Goals / Why / Evolution product surfaces.
5. Failure taxonomy and post-training data loop.
6. Limitations and next empirical layer.
